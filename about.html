COLLEGE MANAGEMENT SYSTEM · RELEASE 0.5.0

One connected view of college life.

CollegeOS is a cross-platform, multi-college application in active development. This release adds a first admissions intake and review workflow plus college membership invitations alongside academic operations, tenant setup, secure sign-in and student records.

Foundation release · Docker Compose on Windows/Linux hosts
01 · CONFIGURE

College workspaces

Install once, create a first college during protected setup, then provision additional college workspaces under a platform administrator.

02 · OPERATE

Academic core

Configure terms and courses, create sections, assign college faculty, enroll students and record class attendance.

03 · PROTECT

Scoped access

Sessions are college-member based. Academic data relationships carry college identifiers, role checks limit operations, and changes produce audit events.
