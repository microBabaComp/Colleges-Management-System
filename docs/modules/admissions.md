# Admissions

**Status:** planned · **Owner:** Registrar · **Version:** 0.1.0 · **Reviewed:** 2026-10-07

## Scope

Configurable application forms, program selection, document checklist, reviewer assignment, decision workflow, offer acceptance and conversion to enrolled student.

## Safeguards

Applicants access only their own application. Scope reviewer access server-side; protect uploaded documents; log decisions and exports; prevent duplicate conversion; provide an accessible status and correction path.

## Data and release notes

Define retention for applicant documents. Release notes include workflow, permission, data, migration and support changes. Every release must record changes here and in the project changelog.
