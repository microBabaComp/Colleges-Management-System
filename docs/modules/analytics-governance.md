# Analytics & governance

**Status:** planned · **Owner:** Data governance · **Version:** 0.1.0 · **Reviewed:** 2026-10-07

## Scope

Role-scoped dashboards, aggregate trends, governed exports, audit search, retention and policy configuration.

## Safeguards

Apply tenant scope before aggregation; suppress small groups where re-identification is possible; log export purpose and actor; expire generated files; avoid personal data in telemetry.

## Data and release notes

Record metric definitions, access rules, retention and dashboard changes per release. Every release must record changes here and in the project changelog.
