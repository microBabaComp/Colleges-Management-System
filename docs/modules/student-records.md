# Student records

**Status:** planned · **Owner:** Registrar · **Version:** 0.1.0 · **Reviewed:** 2026-10-07

## Scope

Canonical student profile, contacts and guardians where applicable, enrollment history, program status, consent and links to academic and finance records.

## Safeguards

Use stable internal identifiers rather than email as a primary key. Apply tenant and resource scope to lookups, exports and attachments. Attribute corrections and review bulk operations.

## Data and release notes

Define retention, deletion, export and correction workflows. Record field, permission and migration changes per release. Every release must record changes here and in the project changelog.
